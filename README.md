# San Diego County site screening map

A single self-contained web map of screened parcels in San Diego County (all 18 cities plus the unincorporated county).

Live site: https://peterefritz-lab.github.io/sd-site-map/

Open that link in a browser (laptop or phone). Street and aerial basemap tiles need an internet connection; the parcel and overlay data are inside the page. This is a screening tool only, not a legal determination.
